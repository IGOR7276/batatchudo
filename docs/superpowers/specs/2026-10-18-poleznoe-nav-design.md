# Дизайн: раздел «Полезное» и единая навигация

Дата: 2026-10-18
Статус: согласовано, к реализации (только каркас)

## Цель

Добавить SEO- и UX-полезный раздел со статьями и объединить его с рецептами под
одним пунктом меню, а также привести навигацию к единому виду на всех страницах.

## Решения

- Раздел-зонтик называется **«Полезное»**, страница `/poleznoe.html`.
- Внутри зонтика: **Рецепты** (`/recepty.html`, без изменений) и **Статьи** (`/articles.html`).
- Меню единое на всех `*.html` (header + footer), охват — все ~157 страниц.
- Статьи хранятся как рецепты: `/articles/<слаг>/index.html`, canonical с `/`.
- Подменю открывается по клику (CSS + немного JS), Escape/клик вне закрывают,
  на мобильных — аккордеон; доступность через `aria-haspopup`/`aria-expanded`.
- На этом этапе — **только каркас**: разметка, меню, хабы, шаблон статьи.
  Контент статей пишется позже.

## Информационная архитектура

| URL | Назначение |
| --- | --- |
| `/poleznoe.html` | Хаб-зонтик: блоки-ссылки на Рецепты и Статьи, списки последних |
| `/recepty.html` | Существующий хаб рецептов (не меняется) |
| `/recepty/<слаг>/` | Существующие рецепты (не меняются) |
| `/articles.html` | Новый хаб статей (пустое состояние + каркас карточек) |
| `/articles/<слаг>/` | Статьи (создаются позже) |
| `/articles/_template/index.html` | Шаблон статьи для копирования |

Breadcrumbs: Главная › Полезное › (Рецепты | Статьи) › страница (+ `BreadcrumbList`).

## Меню

Header (8 пунктов, как сейчас):

```
Главная · Каталог · Выращивание · Растения · Прайс · Полезное ▾ · Контакты · О нас
                                                        ├─ Рецепты
                                                        └─ Статьи
```

- «Полезное» подсвечивается активным на `/poleznoe`, `/recepty*`, `/stati*`.
- Footer, колонка «Разделы»: добавляется пункт «Статьи».
- Реализация: `tools/normalize-nav.mjs` заменяет блок `nav.nav` и колонку
  «Разделы» футера во всех `*.html`, учитывая относительный префикс пути
  (`.` в корне, `../../` внутри `/recepty/…` и `/articles/…`) и активный пункт.
